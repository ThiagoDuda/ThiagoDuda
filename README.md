## 📂 Proyectos

### Root Tycoon

Juego local para aprender Linux con **comandos reales**. Cada nivel corre en un contenedor Docker con un Debian de verdad y el juego valida el **estado del sistema**, no el texto que escribiste. Incluye 11 módulos, 73 niveles, desafío diario y apps de escritorio para Mac y Windows.
